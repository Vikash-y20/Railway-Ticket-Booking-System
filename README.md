
# Railway Ticket Booking System

A simple console-based Railway Ticket Booking System developed using C++.

## Features
- Book railway tickets
- Generate unique PNR numbers
- Display all booked tickets
- Store passenger name and journey details
- Menu-driven interface

## Technologies Used
- C++
- Classes and Objects
- Arrays
- Loops and Conditional Statements

## How to Run

Compile:
```bash
g++ main.cpp -o railway
```

Run on Windows:
```bash
.\railway.exe
```
